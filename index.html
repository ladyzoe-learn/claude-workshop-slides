GIT WORDS

螢幕上會看到的 Git 名詞

pull／clone從 GitHub 下載新版／整本下載從雲端把照片抓回來

你不用打指令，但 Claude 回報時會用這些字，看得懂就好

WHAT PAGES CAN'T DO

GitHub Pages 是展示櫃，不是店面後台

適合：純展示的網頁

  • 活動頁、產品介紹
  • 作品集、說明文件
  • 小遊戲、互動小工具

只有網頁檔：HTML、圖片、程式在瀏覽器裡跑

不適合

資料庫　不能存使用者送來的資料：訂單、會員、問卷結果

後端程式　不能做登入、付款、寄信、權限控管
